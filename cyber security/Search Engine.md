[Shodan](https://www.shodan.io/): 특정 유형의 서버, 장비를 검색하는 도구
[Censys](https://search.censys.io/): 호스트, 웹사이트, 인증서 검색하는 도구
[VirusTotal](https://www.virustotal.com/): 프로그램에 악성코드가 있는지를 검사하는 도구
[Have I Been Pwned](https://haveibeenpwned.com/): 이메일 주소가 유출된 데이터에 있는지 검사하는 도구

[CVE Program](https://www.cve.org/), [National Vulnerability Database](https://nvd.nist.gov/): 보안 취약점들 업로드하는 사이트
[Exploit Database](https://www.exploit-db.com/): 해킹툴들 업로드하는 사이트
